This folder contains external or industry-informed benchmark values used across various KPI comparison analyses in the Hopify SaaS portfolio.

## 📁 File Included

| Filename | Description |
|----------|-------------|
| `hopify_benchmarks_seg_table.csv` | Benchmark targets for key SaaS metrics (e.g., churn rate, NRR, CAC payback) by customer segment: SMB, Mid-Market, and Enterprise. |

## 🔍 How Benchmarks Are Used

These benchmarks are referenced throughout SQL and Python scripts to:

- Flag high-risk metrics by segment
