# 📁 Project Artifacts – Hopify SaaS KPI Analysis

This folder contains final deliverables generated from the Hopify SaaS KPI analysis project, organized into key subfolders for easy navigation and reuse.

---

## 📂 Subfolder Overview

| Folder | Description |
|--------|-------------|
| `01_benchmarks/` | Contains industry-informed benchmark metrics used to evaluate actual performance across churn, NRR, CAC, and other KPIs. |
| `02_sql_output/` | Contains cleaned and aggregated KPI data outputs (in `.csv` format) produced using SQL queries, organized by analysis project. |

---

## 📌 Purpose

These artifacts serve as source data for:
- Executive summary
- Dashboard visualizations
- Python scripts and modeling
- Presentation-ready insights

Each CSV file is named with a consistent prefix to reflect its source and content (e.g., `hopify_churn_`, `hopify_mrr_`, etc.).

---

## 🧠 Note

This folder is read-only by design. If you want to regenerate or modify outputs, use the corresponding SQL scripts located in `/04_code/01_sql/`.
