# 🧾 SQL Output Datasets – Hopify SaaS KPI Analysis

This folder contains pre-exported `.csv` files generated from scenario-driven SQL analysis for the **Hopify SaaS KPI Portfolio Project**. These outputs are organized into three core business analysis themes:

---

## 📁 Project Structure

| Subfolder | Focus Area | Description |
|-----------|------------|-------------|
| `01_project_churn_retention_analysis` | Churn & Retention | Metrics such as churn rate, signup cohorts, retention curves, and support ticket impact. |
| `02_project_revenue_profit_analysis` | Revenue & Profitability | KPIs including top-line revenue, MRR, ARPU, CAC Payback, NRR/GRR, and LTV. |
| `03_project_product_cust_behavior_insights` | Product & Customer Insights | Behavioral trends across order patterns, AOV, subscription habits, and top-performing products. |

Each folder includes scenario-aligned `.csv` outputs ready for reporting, visualization, or modeling.

---

## 🛠️ Regeneration

All datasets are derived from the `/sql/` scripts under `/04_code/01_sql/`, aligned to 13 structured business questions. Outputs can be regenerated by running the corresponding query in your SQL client and exporting results to `.csv`.
