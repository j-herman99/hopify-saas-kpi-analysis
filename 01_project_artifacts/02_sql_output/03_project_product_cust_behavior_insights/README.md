# 🧠 Project 3: Product & Customer Behavior Insights – SQL Outputs

This folder contains SQL-derived outputs that explore customer behavior trends, product-level performance, and subscription engagement in the Hopify SaaS dataset.

Key topics include:
- Top product performance and segment revenue contribution
- Average order value (AOV) and subscription patterns
- Cross-sell opportunities by segment
- Support ticket volume and resolution time
- Monthly churn snapshots and behavioral summaries
