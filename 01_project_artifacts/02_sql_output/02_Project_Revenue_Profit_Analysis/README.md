# 💰 Project 2: Revenue & Profitability Analysis – SQL Outputs

This folder contains SQL-derived outputs that track core financial metrics for Hopify’s SaaS performance across segments, including revenue retention, ARPU, LTV, and active user trends.

Key topics include:
- Monthly recurring revenue (MRR) vs. targets
- Net & gross revenue retention (NRR, GRR) trends
- Expansion revenue and active user patterns
- ARPU performance by segment and product
- CAC payback and customer lifetime value (LTV)
