**Version:** `v1.0`  
📅 Released: June 2025

A scenario-based SQL + Python project that simulates and analyzes a B2B SaaS business called **Hopify**. The project is structured to help analysts evaluate core SaaS KPIs including churn, retention, LTV, CAC, and revenue performance across SMB, Mid-Market, and Enterprise segments.

---

## 🗂️ Folder Structure

| Folder | Description |
|--------|-------------|
| `01_project_artifacts/` | SQL outputs, generated KPIs, benchmark files, and Python scripts by project part |
| `02_documentation/` | Executive summaries, visual slide decks, ERD diagrams, FAQs, and best practices |
| `03_data/` | Database file (`hopify_saas_v1.db`), benchmarks, and supporting reference tables |
| `04_code/` | Python files for database generation, visualizations, and sandbox exploration |
| `05_visuals/` | Static visual assets generated for reporting and storytelling |
| `hopify_sql_scenarios_index.md` | Overview of all SQL scenarios and the business KPIs they support |

---

## 🔍 Main Use Cases

- Customer Churn & Retention Analysis
- Revenue Growth, NRR / GRR Tracking
- LTV, CAC, and Profitability Benchmarking
- Customer Behavior & Product Insights
- Support Ticket Impact on Retention
- Segment-specific SaaS Performance Review
