# 💰 Hopify SaaS Project - Part 2: Revenue & Profitability Analysis

This project evaluates how Hopify earns, retains, and grows revenue across customer segments. The analysis explores recurring revenue (MRR), customer lifetime value (LTV), ARPU, expansion trends, and profitability drivers like CAC and payback period.

---

---

## 🔍 Key Business Questions Answered

- Which segments contribute most to recurring and expansion revenue?
- How efficient is customer acquisition by segment?
- Are we achieving sustainable LTV:CAC ratios and low CAC payback periods?
- Are NRR and GRR improving over time or declining for certain cohorts?
- How do cross-sell patterns vary across segments?
