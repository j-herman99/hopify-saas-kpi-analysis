# 🧪 99_sandbox

This folder contains experimental or exploratory scripts used during the development of the Hopify SaaS KPI Analysis project. These scripts are not directly part of the core analysis pipelines but serve as prototypes, utility tools, or visual proof-of-concept experiments.

## 📊 Script Included

| Filename                             | Description                                                                 |
|-------------------------------------|-----------------------------------------------------------------------------|
| `01_hopify_burndown_chart_simulated.py` | Generates a simulated Agile burndown chart for Hopify v15. Demonstrates realistic progress tracking with a mid-project stall and end-of-sprint catch-up. Useful for visualizing task completion trends over a 15-day sprint. |

## 🔍 Notes
- Intended for internal use and experimentation.
- Not integrated into production pipelines.
- Output: A visual burndown chart using `matplotlib`.
